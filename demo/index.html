Configure a billing control in markup

The attributes generate a fieldset, legend, and radio choices. This example requires JavaScript to create its inputs. 

<form-multi-switch
  name="billing"
  label="Billing frequency"
  choices='[{"label":"Monthly","value":"monthly"},
    {"label":"Annually","value":"annual"}]'
  value="annual"
></form-multi-switch>

Generate a control from application data

This control uses configure(). The button changes its current selection without changing its default or firing an interaction event. 

control.configure({
  name: 'density',
  label: 'Display density',
  choices: [
    { label: 'Comfortable', value: 'comfortable' },
    { label: 'Compact', value: 'compact' }
  ],
  value: 'comfortable'
});
