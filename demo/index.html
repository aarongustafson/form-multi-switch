<form-multi-switch>

Present a native radio group as a segmented control without replacing its inputs. See the README for installation and API documentation.

Keyboard too: Use Tab to reach a group, arrow keys to change its selection, and Space to select.

Declarative Configuration: For JS-driven controls

Generate a group from attributes

Supply a name, accessible label, and JSON choices to have the component generate and manage the controls. If you are using this component in a JavaScript-driven UI, this approach allows you to declaratively define the options without manually creating the <input> elements. 

<form-multi-switch
  name="billing"
  label="Billing frequency"
  choices='[
    {"label":"Monthly","value":"monthly"},
    {"label":"Quarterly","value":"quarterly"},
    {"label":"Annually","value":"annual"}
  ]'
  value="quarterly"
></form-multi-switch>

Pure JS example: Generate a multi-switch from application data

If you want to generate the multi-switch options dynamically, use configure().

This demo also shows how to update the selected value programmatically after the multi-switch has been configured. 

<form-multi-switch id="js-density">
</form-multi-switch>

const control = document.querySelector('#js-density');
control.configure({
  name: 'density',
  label: 'Display density',
  choices: [
    { label: 'Comfortable', value: 'comfortable' },
    { label: 'Compact', value: 'compact' },
    { label: 'Condensed', value: 'condensed' }
  ],
  value: 'comfortable'
});

control.value = 'compact';

Advanced usage: Connect to JavaScript

If your switch needs JavaScript to do its job, point the script attribute at that module. The component loads it and calls its initialize() function, passing in the switch and an AbortSignal you can use to clean up event listeners. Your radios keep their usual appearance until the module is ready.

Example: Switch between a list and a grid

This script reads the selected value and changes how the saved reports are displayed. You don’t need a separate <script> element to load it. 

<form-multi-switch script="./view-behavior.js">
  <fieldset>
    <legend>Saved reports view</legend>
    <label><input type="radio" name="reports-view"
      value="list" checked>List</label>
    <label><input type="radio" name="reports-view"
      value="grid">Grid</label>
  </fieldset>
</form-multi-switch>
<ul data-view-preview>
  <li>Weekly sales</li>
  <li>Stock levels</li>
  <li>Returns</li>
  <li>Customer feedback</li>
</ul>

// view-behavior.js:
export function initialize(control, { signal }) {
  const preview = control.parentElement
    .querySelector('[data-view-preview]');
  const update = () => {
    preview.dataset.view = control.value;
  };
  control.addEventListener('form-multi-switch:change',
    update, { signal });
  update();
  return () => preview.removeAttribute('data-view');
}

[data-view-preview][data-view='grid'] {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 0.5rem;
}

// Your behavior module:
export function initialize(control, { signal }) {
  const preview = control.closest('section')
    .querySelector('[data-preview]');
  const updatePreview = () => {
    preview.style.lineHeight =
      control.value === 'compact' ? '1.2' : '2.4';

  control.addEventListener('form-multi-switch:change',
    updatePreview, { signal });

}
