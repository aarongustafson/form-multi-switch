Import the registration module

This preview imports the local definition helper, which registers the element automatically. Calling the helper again is safe.

Import the guarded definition helper

<form-multi-switch
  name="view" label="View"
  choices='[
    {"label":"List","value":"list"},
    {"label":"Grid","value":"grid"},
    {"label":"Table","value":"table"}
  ]'
  value="list"
></form-multi-switch>

import { defineFormMultiSwitch } from '../define.js';
defineFormMultiSwitch();

The package hasn’t been published. After publication, you can pin the registration module on unpkg and load its stylesheet separately: 

import 'https://unpkg.com/@aarongustafson/form-multi-switch@0.0.1/define.js';
